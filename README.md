# Marcel Schulz

## English

- **C++ Enthusiast:** I love digging into low-level systems, optimizing performance, and crafting my own game engine experiments (2D engines or simple physics demos).

- **Lifelong Learner:** Networking, system internals, custom asset pipelines - I’m always try to learn new stuff and expand my knowledge.

When I’m not knee-deep in C++ code, you’ll find me prototyping new features, exploring different languages and libraries, or bouncing ideas off fellow devs—always up for a chat and collaboration!
